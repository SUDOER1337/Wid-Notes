# Welcome to Nortex

A local-first knowledge workspace. Markdown files are the source of truth. Vim is the primary interaction model. Everything works offline.

## Quick Start

| Key | Action |
|-----|--------|
| `i` | Enter Insert mode (start typing) |
| `Esc` | Back to Normal mode |
| `:w` | Save file |
| `:q` | Quit |
| `Ctrl+S` | Save (alternative) |
| `Tab` | Toggle sidebar open/close |

## Philosophy

- **Files are truth** — no proprietary storage, no hidden database
- **Journals first** — open today's journal immediately on launch
- **Keyboard first** — keybinds and Vim modal editing is the core interaction model
- **Local AI** — AI is a workspace component, never required
- **No cloud, no telemetry** — fully offline

## Getting Around

Open a page from the sidebar. Use `:e <name>` to switch pages. Press `Enter` on the sidebar items to navigate.

Toggle **Markdown Preview** with the command palette (`:` then search "Preview") to see rendered output alongside your raw markdown.
